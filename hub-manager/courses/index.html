Courses and curriculum

Create a course, set its fee and open enrolment.

Create or edit a course

  1. Open Academics → Courses and click New Course (or the edit icon on a card).
  2. Enter the Course Title, description and Instructor / Tutor.
  3. Set Max Students and, for self-paced courses, a Start Date. Modules then open one per week from that date.
  4. Turn on Online course if enrolled students should use the online course player.
  5. Turn on Chargeable course and enter the monthly Course fee (UGX) if students pay. Leave it off for a free course.
  6. Add an optional Course image link, then click Create Course or Save Changes.

Use the Open enrolment / Close enrolment switch on a card to control whether students can apply.

Inside a course

  • Enroll Student: search for a student and add them directly.
  • Add Module and Add Content: build the curriculum, just like instructors do. Drag to reorder.
  • Unblock a stuck student: use the progress icon on a module to tick an item as complete for one student. Only use this when something is genuinely broken for them.
  • Preview as student: see the course as a student does.
Deleting a course

A course with enrolments, check-ins or submissions cannot be deleted. Close enrolment instead.

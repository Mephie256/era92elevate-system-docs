Admin questions

Quick answers.

Why can’t I add a hub?

Adding a hub is for Super Admins only. You can still edit, deactivate and delete hubs.

Why is there no refund button on a payment?

Refunds are for Super Admins, and only for Paid payments made in the last 7 days. Refund older payments from the Flutterwave dashboard.

I changed a role’s permissions. Why has nothing changed?

Access comes from each person’s role, not from the Roles tab. Change the person’s role in Users & Roles instead.

Can I schedule exams?

Not yet. Use Create Assessment for marked work.

A new user says they cannot get in.

They must confirm their email with the 6-digit code first. If the code expired, they can request a new one on the sign-in screen. See Sign in.

Can I delete a user and bring them back later?

No. Deleting is permanent. Deactivate the account instead.

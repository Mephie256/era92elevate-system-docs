Courses and curriculum

Create courses, set fees and open enrolment.

Admins and hub managers share the same course screen. Open Academics → Courses to create a course, choose its instructor, set its start date, switch on the online course player, set a monthly fee and open or close enrolment.

The full steps are in the hub manager course guide. Instructors build the lessons, as shown in the instructor guide.

Deleting a course

A course with enrolments, check-ins, placements or submissions cannot be deleted. Close enrolment to hide it from students instead.

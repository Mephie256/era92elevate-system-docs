Build your course curriculum

Add modules, lessons, videos and quizzes.

Open Academics → Courses. The page is called My Classes. Click Manage → on a course to open its curriculum.

Add a module (a week)

  1. Click Add Module.
  2. Set the Module # (1, 2, 3…), a Title such as “Introduction to Design”, and an optional description.
  3. Click Add Module.

Add a lesson or other content

  1. Click Add Content on the module.
  2. Give it a Title and pick a Type: Lesson, Video, Assignment or Resource.
  3. Optional: paste a YouTube Video URL. It plays inside the lesson for students.
  4. Write the Lesson Notes (or Assignment Instructions). You can add headings, lists, images, code and links.
  5. Tick Students must submit work for this item if students should hand something in instead of just marking it complete.
  6. Set the Duration (minutes) and click Add Content.

Add a quiz to any item

Under Completion Quiz, set a Passing Score (%) (70 by default) and click + Add Question. Choose Multiple Choice (2–5 options; pick the right one with the radio button) or True / False. Students must pass the quiz to complete the item and unlock the next module.

Deleting is permanent

Deleting a module removes its lessons and every submission and progress record students made on them. Deleting a single content item happens straight away, with no confirmation.

Good to know

  • Students cannot hand in an Assignment item until they finish the module’s other items.
  • Work handed in through the course player is marked in Online Course Progress.
  • Only admins can reorder modules or mark a lesson complete for a student. Ask your hub manager if a student is stuck.

Student

Mark your attendance

Scan the QR code or type the 6-character code.

In class, your instructor or hub manager shows a QR code and a 6-character code. You must be signed in to check in.

Scan the QR code

  1. Scan the code with your phone camera.
  2. Elevate opens and shows "Checking you in…".
  3. When you see "You’re checked in!" you are done.

Or type the code

  1. Click the Mark Attendance icon next to your name at the top right (or go to the /attend page).
  2. Type the 6-character code shown on screen, for example A4K9WR.
  3. Click Check In.
MessageWhat to do
Already checked in!Nothing. You are already marked present.
QR code has expired / Code has expiredAsk for the current code. Codes last between 5 minutes and 1 hour.
Session is closedThe register has closed. Talk to your instructor.
Invalid codeCheck the code and type it again. It never contains 0, O, 1, I or L.
Check in before the register closes

When the session is closed, everyone on the course who did not check in is marked absent.
